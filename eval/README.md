### 结论

1. **生成集测不出差别**：问题和原文的最长公共子串中位数 6 字（难题集 2 字），三种配置 R@5 都在 0.98 以上。
   只看生成集会以为检索已经做完了（spec Q8）。
2. **重排是主要收益，且重排模型的选择影响很大**：生成集 R@1 0.82 → 0.96–0.97；难题集上 gte-rerank-v2 只把 MRR 从 0.59 提到 0.62，qwen3-rerank 提到 0.82。代价是 P50 多 1.0–1.7 秒。
3. **全文召回在口语题上是噪声**：不重排时，混合在难题集上比纯向量差（R@1 0.47 → 0.24）；降低全文权重能缓解，
   但仍不如纯向量。重排后权重对结果几乎没有影响（差异不超过 1 题）。线上默认「混合 + 重排（qwen3-rerank）」、权重 1.0（spec D33）。
4. **剩下的错题是词汇鸿沟**：gte-rerank-v2 下难题集 7 题未进前 5，换 qwen3-rerank 后剩 3 题（既往症、等待期、心梗↔疾病免责），
   调检索参数解决不了，留给 M4 的查询改写（spec Q14）。
5. 附表表格（spec Q11）未观察到对召回的影响；评测集审核发现的结构问题记在 spec Q13。
